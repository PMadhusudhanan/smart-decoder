# Smart Decoder (sdcod)

**Smart Decoder** is a powerful command-line tool designed for CTF enthusiasts and cybersecurity professionals. It automatically attempts to decode an input string using multiple popular encoding, cipher, and compression techniques, helping you quickly identify hidden or encoded messages.

---

## 🚀 Features

- Supports decoding of over 25 encoding types including:
  - Base64, Base32, Base85, Hexadecimal
  - URL Encoding, ROT13, ROT47, Morse Code
  - Caesar Cipher, Atbash, Vigenère Cipher
  - HTML Entities, UTF-8/16/32
  - Compression formats: zlib, gzip, bz2
  - And many more...

- Easy command-line usage with clear, color-coded output
- Detects and displays all possible valid decodings

---

## 📦 Installation

```bash
git clone https://github.com/PMadhusudhanan/smart-decoder.git
cd smart-decoder
chmod +x install.sh
./install.sh
```

This will:

- Create a virtual environment `smart-decoder-env`
- Install all required dependencies
- Make the tool executable globally as `sdcod`

---

## 💻 Usage

```bash
sdcod
```

Then input your encoded string and get instant decoding suggestions.

---

## 🔧 Development

- Python 3.10+
- Dependencies listed in `requirements.txt`
- Activate the virtual environment manually if needed:

```bash
source smart-decoder-env/bin/activate
```
